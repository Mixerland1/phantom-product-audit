# Phantom Home — отдельный прототип главной страницы

## Что создано
- `phantom-home.html` — самостоятельная адаптивная главная страница Phantom, подготовленная для согласования.
- **Не заменяет `index.html`**: этот файл остаётся страницей интеграции «Фантом» с 1С:CRM.
- Источники визуальной идеи: Figma MDIS, node `3758:91617` (архитектура с реальным оборудованием), node `3758:91124` (мозаика преимуществ).
- Реальные фотографии: `assets/products/phantom-pro-level-5-cutout.png`, `phantom-pro-level-6-cutout.png`, `phantom-pc-2-cutout.png`, `phantom-ultra-neutral-racks.png`.
- Используемые общие элементы: `assets/footer-next.css`, `assets/footer-layout-v2.css`, `assets/footer-next.js`. CSS и поведение нового hero и header находятся внутри HTML, чтобы прототип не менял другие страницы.

## Структура
1. Первый экран: ценностное предложение, реальные фотографии, три ключевых факта
2. Упрощённая схема записи, по мотивам первого видеослайда
3. Навигация по задачам
4. Шесть преимуществ, по мотивам второго видеослайда
5. Четыре реальные модели
6. Отраслевые страницы
7. Прямые ссылки на проверяемые материалы
8. Компактная форма запроса, открывающая почтовое приложение

## Локальный просмотр
Поместить `phantom-home.html` рядом с `index.html` в `F:\MVP\phantom website\публикация\предпросмотр_руководство`. Изображения и общие файлы должны находиться в соседней папке `assets`.

## Важные ограничения
- AEZA не обновляется автоматически из GitHub. Публикация новой страницы на сервер требует явной синхронизации и отдельной проверки, что `phantom-home.html` включён в копируемые файлы.
- Не запускать `PublishHeader` с целью загрузить новую страницу без проверки, что скрипт вообще поддерживает новый файл.
- Перед включением главной в общеcайтовую навигацию согласовать её, проверить адаптивность, технические утверждения, изображения, форму и accessibility.
- Не затрагивать рабочий сайт `mdis.ru`.
