Ты работаешь в репозитории:

`Mixerland1/phantom-product-audit`

Это **integration-agent задача**, а не page-agent и не новый аудит контента готовых страниц.

Цель: после выполнения отдельных page-agent задач собрать новый сайт в цельную локальную структуру, применить необходимые изменения shared-файлов, проверить ссылки и убедиться, что старые `mdis.ru`-переходы заменены локальными там, где соответствующие страницы уже мигрированы.

Не переписывай готовые страницы заново и не «усиливай» уже прошедший аудит контента.

# 2. Режим работы

Это integration-agent задача.

Обязательно:

- создать отдельную ветку/worktree от актуального `main`;
- не коммитить напрямую в `main`;
- не публиковать на AEZA;
- не менять production `mdis.ru`;
- не менять content готовых страниц без необходимости;
- не создавать новые content-pages «для полноты»;
- не выполнять новый маркетинговый редизайн;
- не заменять фактические данные своими предположениями.

---

# 3. Что считать источником истины

Для локальной структуры сайта:

```text
актуальный main репозитория
```

Для того, какие страницы должны существовать:

```text
реально реализованные и принятые page-agent задачи
```

Для shared-file правок:

```text
Integration manifest соответствующих page-agent задач
```

Если manifest противоречит уже более свежему `main`:

не откатывать свежие изменения;
адаптировать интеграцию к текущему состоянию.

---

# 4. Главный принцип

Эта задача **не должна повторно редактировать контент каждой страницы**.

Нужно проверить и исправить только:

- маршрутизацию;
- shared navigation;
- footer;
- related links;
- stale external links;
- дубли страниц;
- битые asset paths;
- consistency локальных URL;
- отсутствие конфликтов между page-agent реализациями.
