# 7. Не путать CSTA и аудиотранспорт

Это критическое техническое правило.

CSTA используется для программного взаимодействия с АТС и управления/получения событий.

Не писать:

```text
аудио передаётся по CSTA
```

или:

```text
CSTA — протокол записи голоса
```

Корректно:

```text
CSTA используется как программный интерфейс взаимодействия с АТС. Путь аудио зависит от архитектуры конкретной Active-конфигурации.
```

Официальная карточка Phantom Active для HiPath 4000 отдельно указывает:

```text
запись разговоров осуществляется через IP-шлюз АТС HiPath 4000
```

Следовательно, на схеме показать **две логические связи**:

- управляющая / событийная связь CSTA;
- отдельный путь аудио.

# 13. Секция «Как это отличается от обычной записи линий»

H2:

```text
Физическая линия и логический абонент — разные точки контроля
```

Сравнительная таблица:

| | Традиционная запись линий | Селективная Active-запись |
|---|---|---|
| Точка подключения | физическая линия / поток / IP-трафик | программная интеграция с поддерживаемой АТС |
| Изменение состава | может требовать изменения конфигурации подключения | список устройств меняется программно |
| Платы-адаптеры | применяются для физических линий | в опубликованных Active-сценариях не требуются для подключения каждой записываемой линии |
| Зависимость от АТС | определяется типом линии | высокая: нужна поддерживаемая интеграция |
| Централизация | зависит от архитектуры | опубликована как одна из возможностей Active |

Обязательно:

```text
Это сравнение описывает принцип, а не универсальный комплект оборудования.
```
