Мониторинг МЦКРС «Фантом»

Контроль состояния регистратора в современной Linux-ветке Phantom

Модуль мониторинга помогает службе эксплуатации контролировать состояние регистратора Phantom в реальном времени. Он может использоваться через собственный Web-интерфейс или передавать данные во внешнюю систему мониторинга заказчика по SNMP.

Мониторинг – отдельный эксплуатационный контур Phantom Cross

Phantom Logger и Server выполняют основные функции системы записи. Monitoring Agent и Mon Web App служат для наблюдения за состоянием компонентов; они не заменяют ядро регистрации и архив.

Система записи должна быть наблюдаемой до того, как запись понадобится

Эксплуатационная служба получает сведения о состоянии регистратора во время его работы, а не только при обращении к архиву.

Состояние

Эксплуатационная служба видит, что регистратор и контролируемые программные компоненты находятся в ожидаемом состоянии.

Раннее обнаружение

Отклонение можно заметить во время эксплуатации, а не только при попытке найти запись после события.

Единый контур

Данные Phantom можно включить в существующую систему мониторинга предприятия по поддерживаемому интерфейсу.

Распределённые объекты

Для нескольких площадок централизованный мониторинг особенно полезен, поскольку состояние регистраторов не нужно проверять только локально.

Отдельный Web-интерфейс или внешний мониторинг

Модуль рассчитан на два способа использования. Внешний контур определяется инфраструктурой заказчика.

Собственная Web-панель

Phantom Mon Web App получает данные по SNMP и отображает состояние системы в отдельном Web-интерфейсе мониторинга.

Внешний контур

Phantom Monitoring Agent обрабатывает данные и передаёт их по SNMP, чтобы система заказчика могла использовать их в эксплуатационном мониторинге.

Конкретная внешняя система должна поддерживать необходимый вариант SNMP-интеграции.

Phantom Monitoring Agent собирает и передаёт данные

Monitoring Agent получает данные мониторинга, в частности от Phantom Logger, обрабатывает их и передаёт по SNMP.

Состояние системы можно видеть через Web-интерфейс

Phantom Mon Web App формирует отдельную Web-панель мониторинга. Это интерфейс эксплуатационного контроля состояния компонентов, а не поиска и прослушивания переговоров.

Phantom Mon Web App

В документации Phantom Cross 5.5.2 описана отдельная панель мониторинга, получающая данные через SNMP. Адрес и доступность зависят от настройки системы.

Набор параметров зависит от версии и состава системы

МДИС сообщает о мониторинге работоспособности регистратора более чем по 15 параметрам. Конкретный перечень необходимо брать из актуальной документации используемой версии Phantom Cross.

В инструкции по установке 5.5.2 описан контроль состояния серверов, логгеров, служб Phantom Cross, аппаратных плат, системных ресурсов, процесса записи, передачи данных и дисковых разделов. Это области мониторинга, а не полный перечень 15+ конкретных параметров.

Интеграция с существующей системой мониторинга

Monitoring Agent поддерживает передачу эксплуатационных данных по SNMP. Это позволяет включить состояние Phantom в общий мониторинг инфраструктуры без необходимости постоянно открывать отдельную панель.

Граница ответственности

Phantom предоставляет данные мониторинга по SNMP. Приём, дальнейшая обработка и отображение этих данных во внешнем контуре зависят от выбранной системы заказчика и её настройки.

Версию SNMP, структуру OID, traps и перечень доступных объектов следует проверять по актуальной технической документации и конфигурации поставки.

Особенно полезен там, где регистраторов несколько

В распределённых проектах регистраторы находятся на разных площадках, поэтому эксплуатационной службе важно видеть их состояние централизованно. Phantom может передавать данные мониторинга во внешний контур заказчика, где они используются вместе с другими инфраструктурными системами.

Увидеть проблему и пережить отказ – не одно и то же

Мониторинг показывает состояние системы и помогает обнаружить отклонение. Резервирование и передача копий записей решают другую задачу – сохранение работоспособности или данных при отказе отдельных компонентов.

Архитектура Phantom Cross 5.5

Мониторинг помогает эксплуатации, но не заменяет поддержку

Панель мониторинга помогает определить, что состояние системы отклонилось от нормы. Диагностика причины, обновление ПО, ремонт оборудования и восстановительные работы относятся к технической поддержке и обслуживанию.
