Совместимость

Phantom 4.x и Windows

Официальный раздел установки МДИС относит Phantom 4.10 к актуальной Windows-ветке и перечисляет Windows 10, Windows Server 2016 и Windows Server 2019. Поддержку конкретной редакции и сборки ОС необходимо уточнять по документации установленной конфигурации.

Опубликованная видеоинструкция относится к Phantom 4.10. Это не означает, что версия является последним доступным выпуском для всех конфигураций.

Для Phantom 5.x на Astra Linux используются другие документы и процедуры. Прямой автоматический переход с Phantom 4.x на Phantom Cross не подтверждён.

Обновление

Когда требуется модернизация, а не установка обновления

Если меняется операционная система, сервер, интерфейсные платы, типы линий или архитектура системы, задача может требовать отдельного обследования и проекта модернизации.

Совместимость определяется типом линий, платой, АТС, протоколом и версией ПО. Документация Phantom 4 не подтверждает совместимость с любой АТС.
