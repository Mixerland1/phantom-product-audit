# Phantom / МДИС — отложенная публикация двух видеоинструкций на Rutube

**Дата фиксации:** 15 ноября 2026 года  
**Статус:** ожидается проверка актуальности у коллег МДИС и самостоятельная публикация владельцем проекта на Rutube.  
**Ограничение:** до получения проверенных ссылок на Rutube не менять ссылки на действующих страницах; не публиковать исходные MP4 в GitHub, GitHub Releases или тестовом AEZA.

## Зачем нужен этот handoff

При переносе официального сайта МДИС и аудите промптов №39–40 выявлены два архивных видео. Их техническая актуальность **ещё не подтверждена**, поэтому владелец проекта отправляет прямые ссылки коллегам и ждёт решения. До этого момента страницы нового сайта продолжают ссылаться на исходные файлы `mdis.ru`. Это сознательная временная внешняя зависимость.

|---|---|---|---|---|
| 1 | Установка аналоговой платы и программы «Фантом» 2.3 | `support-phantom-2.html` | https://mdis.ru/upload/iblock/698/698df4b84c9601a56bd472681149a94c.mp4 | 253,4 МБ |
| 2 | Установка Phantom 4.10 | `support-phantom-4.html` | https://mdis.ru/upload/iblock/c92/c92d52d725a8b52f6388e629b0c1d53e.mp4 | 78,5 МБ |

Размеры — подписи со страниц, а не повторная проверка текущего размера на диске.

## Принятое решение о хранении

1. **Оригинальные MP4** должны храниться **только в локальном архиве проекта** на диске пользователя: `F:\MVP\phantom website\архив\видео`. Пользователю в чате ранее предоставлен скрипт `Archive-PhantomVideos.ps1` для загрузки оригиналов и записи SHA-256. Наличие файлов на диске и запуск скрипта **не подтверждены**: у агента нет доступа к локальному диску `F:`.
2. Не коммитить MP4 в репозиторий, не добавлять в GitHub Releases, не переносить оригиналы на тестовый AEZA. Запущенная ранее попытка переноса в GitHub Releases **была отменена**; релиз `phantom-support-media-20261115` не существует (подтверждено 15.11.2026).
3. **Публичная версия видео** после подтверждения коллегами публикуется **пользователем на Rutube**. Пока ссылки не получены, не придумывать URL и не подменять оригинальные ролики похожими материалами.
4. **Архивы установочных дистрибутивов** Phantom 2 (3 RAR, 1 ZIP) — **другая категория файлов**: они уже перенесены в GitHub через [PR #85](https://github.com/Mixerland1/phantom-product-audit/pull/85) и не относятся к запрету на размещение исходных MP4.

## Что нужно получить от коллег

Для каждого ролика отдельно:
- актуальна ли информация для соответствующей версии Phantom;
- нет ли ошибочных или небезопасных рекомендаций по установке;
- оставлять ли видео в публичном разделе документации либо только во внутреннем архиве;
- требуется ли заменить/обновить инструкцию или сопроводить её явной датой и указанием устаревшей версии.

Не считать ролик пригодным к публикации только потому, что он имеется на `mdis.ru`.

## Действия в следующей сессии после ответа коллег

1. Получить от пользователя результат проверки **по каждому из двух видео** и, если видео разрешены к публикации, точные ссылки на опубликованные им ролики Rutube.
2. Проверить, что ссылки открывают нужные ролики; сверить название, версию, назначение. Не выдумывать продолжительность/редакцию и не утверждать, что видео актуально без подтверждения.
3. Изменить **только соответствующие ссылки** в `support-phantom-2.html` и `support-phantom-4.html` с исходных MP4 на подтверждённые Rutube URL. При необходимости скорректировать текст кнопок на «Смотреть видео». По возможности оставить карточки и контекст версии неизменными.
4. Если коллеги признали ролик устаревшим, **не** публиковать его и **не** ставить новую ссылку; согласовать, нужно ли скрыть карточку или разместить предупреждение, не изменяя историческую документацию произвольно.
5. Сохранить описание решения и Rutube URL в этом handoff. Не добавлять исходные видео в репозиторий.
6. Провести адресный браузерный QA для обеих страниц на 375, 768, 1024, 1440 px в светлой/тёмной теме, проверить внешние ссылки и полный штатный Chromium QA. Вносить правки через отдельную ветку и PR → `main`.
7. Только после завершения PR/QA сообщить пользователю, что можно вручную запустить ярлык «Обновить Phantom» для тестового AEZA. Самостоятельно не публиковать сайт; production `mdis.ru` не трогать.
