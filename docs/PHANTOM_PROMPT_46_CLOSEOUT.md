## 5. Браузерные проверки

Постоянный Chromium-набор `tools/browser_qa.py` расширен с 46 до **всех 55 канонических страниц**, четыре разрешения `375/768/1024/1440` px × две темы = **440 сценариев**. Интеграционный workflow обновлён: сначала статический аудит промпта №46 и SHA-манифестов, затем полный реальный Chromium с изображениями, меню, темами, ссылками и overflow. Машинный JSON включён в CI-артефакты.

**Приёмочный Chromium:** проверяется отдельно в PR. Не считать результат PASS до появления успешного GitHub Actions run на итоговом коде ветки.
