## История и проверки

- Одобренные пользователем переработанные схемы перенесены в `main` через PR #8. В PR #9 исправлены надпись «Триком» и четыре обозначения SIP в изображении ТРИКОМ GIP.
- Ветвь `page/connection-schemes-13` ранее содержала четыре старые, более компактные версии (суммарно 415 290 байт), которые не использовались на новой странице. Они удалены **только из этой ветки** 12.11.2026. GitHub больше не содержит там текущей папки `assets/schemes/`. История коммитов сохранена.
- Суммарный размер работающего набора в `main` — 559 574 байта. Все четыре WebP имеют разные SHA по сравнению со старой веткой.
- Сохранение топологии и всех соединений при генеративной переработке требует самостоятельной инженерной проверки перед публикацией в production; проверка существования файлов и чтения WebP не заменяет её.
- Для тестового стенда: синхронизация штатным «Обновить Phantom» и проверка `PUBLISHED` + `DONE`, HTTP 200, SHA-256 и адаптивного отображения. **Коммиты в GitHub не подтверждают обновление AEZA**.

## Публичные редакционные правила

Страница представляет схемы как штатные материалы нового официального сайта. Запрещено возвращать в HTML пояснения «обработанная копия», «оригинал», «источник», ссылки на старый `mdis.ru` и внешние резервные изображения. Историческое происхождение файлов, если понадобится, должно обсуждаться только во внутренней документации и инженерном контроле.
